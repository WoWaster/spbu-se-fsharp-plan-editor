# DSL для описания учебных планов СПбГУ

Утилита для описания учебных планов в формате СПбГУ.
Может быть удобна для (а) версионирования учебных планов; (б) их анализа; (в) внесения изменений с последующих экспортом.

## Фичи

- [x] DSL "от семестров"
- [ ] DSL "от предметов"
- [ ] Экспорт в `.xlsx`
- [ ] Экспорт в `.docx`
- [ ] Интеграция с https://github.com/resueman/curriculum-parser (или https://github.com/spbu-se/spbu-curriculum-tool ?)
- [ ] Импорт из выгрузок ИС Учебные планы
- [ ] Валидация учебного плана (30 з.е./семестр, использование всех компетенций/другое)
- [ ] Поддержка факультативов

## Как это использовать

Описывать учебный план придётся на F#, в основном с помощью синтаксиса Computation Expressions.

Пример описания в данный момент содержится в проекте `PlanEditorCLI`.
Для запуска можно использовать команду:
```console
$ dotnet run --project PlanEditorCLI
```
